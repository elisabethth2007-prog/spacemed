In this session we discussed the energy consumption of LLMs, in comparison to the brain that uses only
20 watts. Then we got an introduction to High Performance Computing, including technical aspects as well as typical problem classes that require HPC. After the break, we went to the cluster and tried ourselves how to allocate resources (select nodes, partitions) and perform one ore multiple jobs.
1 node = 1 computer/VM; 1 core = 1 CPU core inside that node
